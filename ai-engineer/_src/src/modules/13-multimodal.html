Vision: model analizuje obraz

import Anthropic from "@anthropic-ai/sdk"; import { readFile } from "node:fs/promises"; const client = new Anthropic(); const image = (await readFile("paragon.jpg")).toString("base64"); const res = await client.messages.create({ model: "claude-sonnet-5-5", max_tokens: 1500, messages: [{ role: "user", content: [ // obraz PRZED pytaniem — zwykle daje lepsze wyniki { type: "image", source: { type: "base64", media_type: "image/jpeg", data: image } }, { type: "text", text: `Odczytaj paragon. Zwróć JSON: { sklep, data (YYYY-MM-DD), pozycje: [{nazwa, cena}], suma }. Jeśli coś jest nieczytelne, wpisz null — nie zgaduj.` }, ], }], }); console.log(res.content[0].type === "text" ? res.content[0].text : "");

Koszt obrazu

Obraz zamieniany jest na tokeny proporcjonalnie do liczby pikseli (w Claude orientacyjnie szerokość × wysokość / 750). Zdjęcie 1000×1000 ≈ 1300 tokenów. Duże obrazy są skalowane w dół.

Jakość

Przytnij do istotnego fragmentu, zadbaj o czytelność tekstu. Mały, rozmazany tekst to główne źródło błędów OCR.

Ograniczenia

Precyzyjne liczenie obiektów, dokładne położenie przestrzenne i bardzo drobne detale bywają zawodne. Weryfikuj krytyczne dane.

PDF bezpośrednio do modelu

const pdf = (await readFile("umowa.pdf")).toString("base64"); const res = await client.messages.create({ model: "claude-sonnet-5-5", max_tokens: 3000, messages: [{ role: "user", content: [ { type: "document", source: { type: "base64", media_type: "application/pdf", data: pdf } }, { type: "text", text: "Wypisz strony umowy, okres wypowiedzenia i kary umowne. Podaj numer strony dla każdej informacji." }, ], }], });

Model widzi zarówno tekst, jak i wyrenderowane strony — rozumie tabele, wykresy i skany. Dla dużych zbiorów dokumentów nadal lepszy jest RAG (moduł 10), ewentualnie z multimodalnym parsowaniem przy indeksowaniu.

Generowanie obrazów

import OpenAI from "openai"; import { writeFile } from "node:fs/promises"; const openai = new OpenAI(); const img = await openai.images.generate({ model: "gpt-image-2", // przykładowe ID — sprawdź aktualną listę modeli obrazowych prompt: "Zdjęcie produktowe ręcznie robionego ceramicznego kubka w kolorze butelkowej zieleni, " + "na drewnianym stole, miękkie poranne światło, płytka głębia ostrości, bez tekstu", size: "1024x1024", }); await writeFile("kubek.png", Buffer.from(img.data![0].b64_json!, "base64"));
Prompt do obrazuOpisuj: obiekt, otoczenie, oświetlenie, styl/medium (zdjęcie, akwarela, ilustracja wektorowa), kompozycję i kadr, czego ma nie być. Pamiętaj o prawach: nie generuj znaków towarowych, postaci chronionych ani wizerunków prawdziwych osób.

Audio: mowa ↔ tekst

import OpenAI from "openai"; import fs from "node:fs"; const openai = new OpenAI(); // Speech-to-text const transcript = await openai.audio.transcriptions.create({ file: fs.createReadStream("spotkanie.mp3"), model: "gpt-transcribe", // przykładowe ID; open-source alternatywa: Whisper lokalnie language: "pl", // podpowiedź języka poprawia dokładność }); console.log(transcript.text); // Text-to-speech const speech = await openai.audio.speech.create({ model: "gpt-4o-mini-tts", voice: "alloy", input: "Twoje zamówienie zostało wysłane i dotrze jutro.", }); fs.writeFileSync("odpowiedz.mp3", Buffer.from(await speech.arrayBuffer()));

Architektury agenta głosowego

Kaskada: STT → LLM → TTS

🎤 STT→🧠 LLM + narzędzia→🔊 TTS

Pełna kontrola, dowolny LLM, łatwe logowanie tekstu. Latencja sumuje się (zwykle 1–3 s). Streamuj każdy etap.

Speech-to-speech (realtime)

🎤 audio→🧠 model audio→🔊 audio

Najniższa latencja, naturalna intonacja, obsługa przerywania. Mniej kontroli, połączenie przez WebSocket/WebRTC.

W rozmowie głosowej kluczowe są: wykrywanie końca wypowiedzi (VAD), obsługa przerwania (użytkownik zaczyna mówić, gdy agent mówi), krótkie odpowiedzi i brak formatowania (nie da się przeczytać tabeli).

Wideo

Rozumienie: modele natywnie obsługujące wideo przyjmują plik bezpośrednio. Uniwersalna metoda dla innych: wytnij klatki (np. 1 na sekundę, ffmpeg), wyślij je jako serię obrazów + transkrypcję audio. Generowanie: modele tekst→wideo tworzą krótkie klipy; są drogie i wolne, w aplikacjach zwykle obsługiwane asynchronicznie (zadanie w tle + webhook/polling).

Embeddingi multimodalne

Modele typu CLIP umieszczają obrazy i teksty w tej samej przestrzeni. Możesz wyszukiwać zdjęcia opisem tekstowym albo znajdować podobne produkty po zdjęciu.

from sentence_transformers import SentenceTransformer from PIL import Image import glob model = SentenceTransformer("clip-ViT-B-32") # wersja wielojęzyczna: "clip-ViT-B-32-multilingual-v1" (dla tekstu) paths = glob.glob("produkty/*.jpg") img_emb = model.encode([Image.open(p) for p in paths], normalize_embeddings=True) query = model.encode(["red sneakers on white background"], normalize_embeddings=True) scores = (query @ img_emb.T)[0] for i in scores.argsort()[::-1][:5]: print(f"{scores[i]:.3f} {paths[i]}")
Budujesz asystenta telefonicznego dla przychodni. Najważniejsza jest naturalność i krótki czas reakcji, ale musisz też logować treść rozmów i wywoływać system rezerwacji. Co rozważysz?
Obie architektury głosowe są realne — wybór to trade-off między latencją/naturalnością (realtime) a kontrolą i dowolnością modelu (kaskada). Ważne, że obie obsługują narzędzia i logowanie.
